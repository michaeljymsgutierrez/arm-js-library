# Documentation

ARM centralizes data management for JavaScript apps: reactive collections, request
deduplication, and a consistent set of record methods. Start with
[Getting Started](/docs/getting-started) to wire up your first `ApiResourceManager`
instance, then [Configuration](/docs/configuration) to point it at your API.

- **[Getting Started](/docs/getting-started)** - install the package and create your first ARM instance.
- **[Configuration](/docs/configuration)** - host, namespace, headers, and the rest of the required/optional setup.
- **[Guides](/docs/guides/request-functions)** - request functions, collection records, root scope, and the utility belt, each with a "Try it live" link running the example against a real (in-repo) API.
- **[API Reference](/docs/api-reference)** - the full public API, generated straight from the library's JSDoc comments.
