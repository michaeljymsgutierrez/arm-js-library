# isNumber()

Returns `true` if the value is a number (including `NaN` and `Infinity`).

**Kind**: global function  

| Param | Type | Description |
| --- | --- | --- |
| value | <code>\*</code> | The value to check. |

**Example**  
```js
ARM.isNumber(42)    // true
ARM.isNumber('42')  // false
```
