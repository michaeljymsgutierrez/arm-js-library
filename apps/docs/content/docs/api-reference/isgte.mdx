# isGte()

Returns `true` if `value >= other`.

**Kind**: global function  

| Param | Type | Description |
| --- | --- | --- |
| value | <code>number</code> | The value to compare. |
| other | <code>number</code> | The threshold. |

**Example**  
```js
ARM.isGte(5, 5) // true
ARM.isGte(4, 5) // false
```
