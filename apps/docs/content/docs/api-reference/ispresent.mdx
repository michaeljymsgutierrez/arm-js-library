# isPresent()

Returns `true` if the value is not empty. Inverse of `isEmpty`.

**Kind**: global function  

| Param | Type | Description |
| --- | --- | --- |
| value | <code>\*</code> | The value to check. |

**Example**  
```js
ARM.isPresent([1])  // true
ARM.isPresent([])   // false
```
