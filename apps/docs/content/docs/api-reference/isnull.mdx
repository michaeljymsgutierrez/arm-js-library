# isNull()

Returns `true` if the value is strictly `null`.

**Kind**: global function  

| Param | Type | Description |
| --- | --- | --- |
| value | <code>\*</code> | The value to check. |

**Example**  
```js
ARM.isNull(null)      // true
ARM.isNull(undefined) // false
```
