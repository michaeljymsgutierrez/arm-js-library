# isNil()

Returns `true` if the value is `null` or `undefined`.

**Kind**: global function  

| Param | Type | Description |
| --- | --- | --- |
| value | <code>\*</code> | The value to check. |

**Example**  
```js
ARM.isNil(null)      // true
ARM.isNil(undefined) // true
ARM.isNil(0)         // false
```
