# sum()

Returns the sum of all values in an array of numbers.

**Kind**: global function  
**Returns**: <code>number</code> - The total sum.  

| Param | Type | Description |
| --- | --- | --- |
| objects | <code>Array.&lt;number&gt;</code> | The array of numbers to sum. |

**Example**  
```js
ARM.sum([10, 20, 30]) // 60
```
