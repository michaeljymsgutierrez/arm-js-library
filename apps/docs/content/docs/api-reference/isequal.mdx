# isEqual()

Returns `true` if two values are deeply equal.

**Kind**: global function  

| Param | Type | Description |
| --- | --- | --- |
| value | <code>\*</code> | The first value. |
| other | <code>\*</code> | The second value. |

**Example**  
```js
ARM.isEqual({ a: 1 }, { a: 1 }) // true
```
